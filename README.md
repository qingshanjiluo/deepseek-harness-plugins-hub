## 本合集：qingshanjiluo 已实现插件

下列 47 个插件均为真实可加载的 Cordis 函数工具插件（`export const name` / `inject=['tools']` / schemastery `Config` / `apply`，工具经 `@deepseek-ai/dsh-tools` 的 `defineTool` 由 `ctx.tools.register` 注册，均带 `output.schema`+`render`）。每仓库自带确定性单元测试与构建产物加载冒烟（install→tsc→build→vitest→load-smoke 全绿）。早期虚构 API（`createPlugin(settings,tools,commands)`、`ctx.tools.register({handler})`、`zod`、浏览器 `client/` 半边）已整体重写移除；命令 / HTTP / 视觉等外部化能力通过可注入的 `runCommand` / `fetch` 接缝实现，单测喂假数据、不触发真实进程或网络。含 3 个自研新插件：dsh-subagent-mode、dsh-context-manager、dsh-vision-ocr。

安装（本地目录直接 link，无需先发布到 npm；发布后亦可按包名安装）：

```
npx -y @deepseek-ai/dsh plugin --profile web add @qingshanjiluo/<插件名>
```

启用后需重启 DSH 生效；重启前可用 `dsh --profile web --dump-config` 预览某插件是否已纳入 bundle。
